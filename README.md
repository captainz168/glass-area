# วัดพื้นที่กระจก

เครื่องมือวัดพื้นที่ผนังกระจกและวัสดุ façade (ACP, terracotta, หิน, louver, mullion/transom) จากแบบ DWG, DXF, PDF สแกน หรือรูป แล้วสรุปเป็นตารางขนาดแผ่น จำนวน และปริมาณ ไว้ประมาณราคาและสั่งวัสดุ

ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์แบบที่เปิดไม่ถูกส่งไปที่ใด

## ใช้งาน

- **ออนไลน์:** เปิดลิงก์ GitHub Pages ของ repo นี้ด้วย Chrome หรือ Edge รุ่นใหม่
- **ออฟไลน์:** ดาวน์โหลด `index.html` แล้วดับเบิลคลิกเปิด

คู่มือใช้งานฉบับเต็ม: [คู่มือใช้งาน เครื่องมือวัดพื้นที่กระจก](https://claude.ai/code/artifact/853e1ef6-72d7-4deb-8287-c6cc1784017d)

## ไฟล์ที่เปิดได้

| ไฟล์ | วิธีวัด |
| --- | --- |
| DWG (R13 ขึ้นไป), DXF แบบ ASCII | คลิกในแผ่น เครื่องมือหาขอบเอง |
| PDF สแกน, JPG, PNG | ตั้งสเกลจากเส้นมิติ แล้ววาดขอบเอง |

## ข้อควรรู้

- ระบบกรอบ วัสดุ และรายการโครงการเก็บในเบราว์เซอร์ของแต่ละเครื่อง ไม่แชร์ข้ามคนหรือข้ามเครื่อง
- ตัวอ่าน DWG เป็นโอเพนซอร์ส บางไฟล์อาจอ่านไม่ครบ งานสั่งวัสดุจริงควรเทียบกับ DXF ที่แปลงด้วย ODA File Converter
- ตัวเลขจากภาพสแกนเหมาะกับการประมาณราคา

## อัปเดตเวอร์ชัน

อัปโหลด `index.html` ตัวใหม่ทับไฟล์เดิม GitHub Pages จะอัปเดตเองภายในไม่กี่นาที
